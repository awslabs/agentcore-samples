# AutoGen hello world (retired)

This sample is no longer distributed for new deployments. [Microsoft has archived AutoGen](https://github.com/microsoft/autogen) and recommends [Microsoft Agent Framework](https://learn.microsoft.com/en-us/agent-framework/overview/) for new projects.

- **Maintaining an AutoGen app?** Start with [Microsoft’s AutoGen migration guide](https://learn.microsoft.com/en-us/agent-framework/migration-guide/from-autogen/). It covers framework migration, not deployment to AgentCore.
- **Learning how a Python agent calls a tool on AgentCore Runtime?** See the [Strands weather tool and Runtime entrypoint](../../../01-features/02-host-your-agent/01-runtime/01-hosting-agents/01-http-protocol/01-strands-bedrock/agent.py). It demonstrates the same basic tool-call pattern without requiring AutoGen; it is not a drop-in replacement for an AutoGen application.

Removing the example does not change existing deployments. The [historical source](https://github.com/awslabs/agentcore-samples/tree/5cca7e89f8109115766b9f7df3f0b7e98ca9eab1/03-integrations/agentic-frameworks/autogen) is available for reference.
